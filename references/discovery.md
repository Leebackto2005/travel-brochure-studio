# 需求沟通与样张确认

用于新制作、整册重排或资料存在冲突的任务。通过逐步澄清、比较方案和确认样张，提前发现会造成大面积返工的选择；不用固定问卷要求每个用户回答所有问题。明确的局部修改仅核对与改动有关的事项。

## 1. 先看材料，再提出问题

先读取用户提供的行程、海报、参考模板及当前版本，并检查历史对话。简述已知条件，例如产品天数、现有版式、用户明确要保留的页，再指出最值得先确认的一个问题。材料中的事实冲突要具体到文件或条目，不能笼统地说“请补充需求”。

根据任务从下表选择尚未明确且影响较大的事项；这是一份代理检查表，不要原样整表发给用户填写。

| 需要了解的方面 | 能提前减少的返工 |
|---|---|
| 谁看、在哪里看：游客、销售、渠道；手机转发或打印 | 字号、信息密度、纸张尺寸和文件体积 |
| 已选模板必须保留哪些部分，哪些允许调整 | 配色、图框、分栏、装饰和页序 |
| 封面使用原海报还是新设计；允许长页还是整册统一尺寸 | 满版、完整画面与统一A4之间的取舍 |
| 必须突出的卖点；全文保留还是允许概览摘要 | 封面信息、正文容量和续页数量；费用条款不能擅自删减 |
| 图片由谁提供，允许另找真实照片或使用AI示意吗 | 素材风格、真实性、缺图占位和后续换图成本 |
| 酒店展示数量、房型配对，餐食和车辆展示方式 | 每页图框数量、主体大小以及参考图与服务承诺的区别 |
| 价格、日期、航班、餐宿及费用包含是否存在冲突 | 业务内容错误；不要由视觉参考推断产品事实 |
| 最终需要什么可编辑源文件、是否固定页数、何时交稿 | 导出路线、交付包和制作优先级 |

资料已经给出答案时直接引用并采用，只有出现冲突或选择会明显影响结果时才再确认。不要向用户询问脚本、选择器、JSON等内部实现细节。

## 2. 一轮解决一个重点

通常每轮只问一个主要问题；确实互相依赖时最多合并3个短问题。尽量给2—3个具体选项，说明各自取舍，并给出适合当前材料的推荐。用户也可以直接自由回答。收到答案后更新理解，再决定下一轮，不机械地按清单逐项盘问。

可根据资料采用下面这样的问法，不能把示例选项当作默认产品事实：

- 用途：“这份主要在哪里使用？A 手机转发阅读；B 打印给客人；C 两者都要。这个选择会影响字号、纸张比例和导出版本。”
- 封面：“海报是长图。A 保留原比例做长页封面，画面完整满版；B 整册统一A4，完整海报等比放入并留同色边。你更倾向哪一种？”
- 模板：“参考模板中哪些必须原样保留？A 图框和分栏都保留；B 保留配色与风格，允许调整图框。已要求严格套版时，不再问这题。”
- 酒店：“同页放四家会缩小图片。A 四家同页，信息集中；B 拆成两页，客房更清楚。根据用户已确定的页数限制给出推荐。”
- 冲突：“正文写晚餐包含，表格写自理，请确认采用哪一项。其他页面和素材整理可以先继续。”

如果有结构化提问工具，可按工具约定使用；没有则直接在对话中提问。文字问答工具不用于要求上传文件。需要查看实物样张时先生成可打开的预览链接，再提出针对样张的具体问题。

## 3. 形成简短制作约定

在已有回答基础上，用一小段文字或简短列表列出：用途与交付格式、选定模板及允许变化范围、尺寸和页序、素材风格、已确认业务口径、仍待补充的资料。聊天内记录即可；项目已有说明文件时可以同步，不强制再造一套文档。

未选定视觉方向时，给2—3个有实际区别的方向，说明信息密度、图片大小和页数的取舍，并推荐一个。用户已选原模板时，仅比较模板内的处理方式，不重新设计多个无关方案。

把问题分开处理：

- **影响事实或大范围布局、需要回答的事项**：等待回答再完成依赖它的部分。用户未回复不等于同意。
- **可逆的偏好或明确暂缓事项**：可以提出推荐，并按用户允许的范围先做带说明的初稿；不把暂定信息伪装成最终事实。

等待期间继续提取内容、盘点素材、记录来源和制作不依赖该答案的图框。不要仅为了得到一次“可以开始”而停下；需要用户确认的应是具体选择或已经做出的样张。

## 4. 用实际样张确认，再扩展整册

新设计默认先做1—2页最能暴露排版问题的实际样张，例如图多的酒店页、字多的行程页。样张使用已确认的真实内容；缺图时明确标记占位。先自行检查溢出和裁切，再提供预览，说明希望用户确认的具体点：照片大小、文字密度、标题风格和配色。

用户确认样张后，记录已接受的参数，再沿用至其他页面。已有确认海报、样张或既定模板的局部改动无需重复走样张审批。用户明确说“按你判断直接做”“先做完整初稿”时，可跳过等待，说明假设并继续制作；关键业务事实仍不能编写。

如果用户更改已经确认的方向，简短指出会影响哪些页面或资料，更新制作约定后执行。不要擅自把一次局部反馈扩展成整册重做，也不再询问没有受影响的已确认事项。

## 5. 何时结束沟通进入制作

满足当前任务所需的关键事实、版式和交付约束已明确，剩余资料已有用户认可的处理方式，且样张已确认或用户已要求直接制作，即可进入 [SKILL.md](../SKILL.md) 的工具流程。沟通次数没有最低要求；目标是提前解决分歧，确认后持续推进到完成交付。
