# 严格模板填充

用户最新要求“请严格按照模板来整理内容”优先于此前“参考大概形状”。原SVG是几何真源，PNG/PDF用于视觉比对，不加入其原示例行程事实。

严格版保留1080×1600画布比例，映射到高297mm的PPT页面；不会为了A4强行拉伸。要标准A4打印可在打印时等比适配。所有原始几何、文字均转换为原生PowerPoint对象，照片可更换，未把整页压成一张图。

## 填充数据

先catalog查看槽位ID、原文和坐标。JSON结构：

```json
{
  "template_sha256":"从catalog复制的hash",
  "texts":{"text-04":{"old":"五日旅程","new":"做客海南"}},
  "bodies":{"body-01":"已确认的简短摘要"},
  "photos":{"photo-01":{"path":"photos/main.jpg","fit":"cover","focus":[0.5,0.5],"source":"用户提供","verified":true}}
}
```

相对路径相对fill.json。图片完整保留用contain；cover按焦点裁切。不会修改原图文件，不自动生成图片。正文只替换本槽位的灰条，其他图形和坐标不动。替换文案超过原框容量时报错，不能自动缩小原字号。原文不一致、未知槽位或模板hash变化会拒绝。

多页填充用顶层 `pages: [{texts,bodies,photos}, ...]`，每页复制原模板；顶层template_sha256和相对图片目录共用。不会自动删减长文或推断如何分页，先由代理分配完整内容，再逐页渲染。SVG的text只有基线锚点没有文本框，转换时创建足够容纳字体度量的原生框，并保持start/middle/end锚点；不移动原图形。

四份模板使用Noto CJK字体；当前环境缺少原字体，工具映射微软雅黑/宋体。原位置与字号保持，字形、字宽可能有差异，必须看渲染。若用户要求字体也完全一致，先安装/提供有授权的原字体并修改字体映射，不能虚称已像素还原。

## 事实与内容映射

对每个槽位记录事实来源。航班、酒店、餐食、包含/不含/自愿自费、免责句均从最新文档或用户确认提取；没有就待补，不从视觉模板猜。四天行程不能变成模板的五天。完整双语过长时使用同结构续页，摘要仅用于概览并另附完整行程。

当前脚本转换范围针对这四份已提供SVG的rect/circle/直线与折线路径/text，不是通用任意SVG渲染器。其他SVG遇到不支持的元素应停止并扩展转换后验证，不能默默忽略。只有PNG的蓝橙/清新模板需要先重建可编辑模板并逐项对照，不能当作已有精确转换能力。

交付时附geometry检查、字体替代说明、逐页PNG/PDF；审美复核与业务核对单独报告。用户实际行程未全部填入时，应明确称为模板或填充示例。
